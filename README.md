# Конвертер единиц

Консольная программа на Python для перевода единиц измерения.

## Возможности

- Километры -> мили
- Килограммы -> фунты
- Цельсий -> Фаренгейт
- Метры -> футы
- Литры -> галлоны
- Цельсий -> Кельвин
- Фаренгейт -> Цельсий (новое)
- Сантиметры -> дюймы (новое)
- Часы -> минуты (новое)

## Новый функционал

- Можно выполнять несколько преобразований подряд.
- После каждого преобразования программа спрашивает: "Хотите выполнить ещё одно преобразование? (да/нет)".
- Обрабатывается некорректный ввод: нечисловое значение, неверный номер преобразования, неверный ответ на вопрос о продолжении.
- Результаты округляются до 2 знаков после запятой.

## Запуск

    python main.py
